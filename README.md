# Sakura Theme - WordPress WooCommerce

Тема WordPress для японского ресторана "Цветение сакуры" (Infiniti).

## Установка

1. Скопировать папку `sakura-theme` в `/wp-content/themes/`
2. Активировать тему в админке WordPress
3. Установить WooCommerce

## Требования

- WordPress 6.x
- WooCommerce 8.x+
- PHP 8.0+

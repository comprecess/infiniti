# INFINITI UI Reference Modules

Этот документ описывает эталонные UI паттерны, выявленные в ходе аудита зрелых модулей платформы INFINITI (Talents, Customers, Invoices, Activities, Dashboard). Цель — обеспечить визуальное единообразие новых модулей (Growth & Exit Program) с существующим дизайном.

## 1. Эталонные модули (Reference Modules)

В качестве эталонов были проанализированы следующие модули:
- **Talents / Customers:** Эталон для списков, карточек сущностей, форм редактирования и модальных окон.
- **Invoices / Activities:** Эталон для табличных данных, статусов, фильтров и временных шкал.
- **Dashboard:** Эталон для виджетов, сводной статистики и графиков.

## 2. Основные UI Паттерны

### 2.1. Цветовая палитра (Dark Theme Only)
Платформа INFINITI использует **исключительно темную тему**. Использование белого фона (`#ffffff`, `white`) или светлых оттенков (`#f8f9fa`, `#e9ecef`) **строго запрещено** в контентной части страниц.

*   **Фон карточек (Card Background):** `$brand-900`
*   **Фон инпутов и внутренних блоков:** `$brand-800`
*   **Акцентный цвет (Primary Accent):** `$brand-500` (кнопки, активные состояния, чекбоксы)
*   **Hover состояния (Hover):** `$brand-400`
*   **Основной текст (Primary Text):** `$gray-50` или `$white`
*   **Вторичный текст (Secondary Text):** `$gray-300` или `$gray-400`
*   **Границы и разделители (Borders):** `$gray-500` или `$gray-600`
*   **Цвета статусов:** `$mint-500` (Успех/Завершено), `$cherry-500` (Ошибка/Отмена)

### 2.2. Паттерн Карточки (Card Pattern)
Основан на виджете `RecentCard`.
*   **Фон:** `$brand-900`
*   **Отступы (Padding):** `32px` (для виджетов дашборда может быть `24px`)
*   **Скругление (Border Radius):** `8px` (или `12px` для крупных блоков)
*   **Внутренние отступы (Gap):** `24px` между секциями, `16px` между элементами.
*   **Тени:** Не используются или минимальные темные тени. Белые или светлые тени запрещены.

### 2.3. Типографика (Typography)
Основана на шрифте `Space Grotesk` (`$fontSpaceGrotesk`).
*   **Заголовок страницы:** `32px`, `font-weight: 700`, `letter-spacing: -0.03em`, цвет `$white`.
*   **Заголовок карточки/секции:** `18px` или `20px`, `font-weight: 600` или `700`.
*   **Подзаголовки:** `24px`, `font-weight: 500`.
*   **Основной текст:** `14px` или `16px`, `font-weight: 400` или `500`.

### 2.4. Кнопки (Buttons)
*   **Primary (ButtonBlue):** Фон `$brand-500`, цвет текста `$white`, `border-radius: 8px`, отступы `10px 12px` (или `10px 20px` для крупных).
*   **Secondary (ButtonBrand):** Фон `$brand-800`, цвет текста `$gray-50` или `$brand-500`, `border-radius: 8px`.

### 2.5. Формы и Инпуты (Inputs)
Основано на `CustomInput`.
*   **Фон:** `$brand-800`
*   **Высота:** `48px`
*   **Скругление:** `8px`
*   **Цвет текста:** `$gray-400` или `$gray-50`
*   **Границы:** Обычно без видимых границ, либо `1px solid $gray-600`. При фокусе граница или тень цвета `$brand-500`.

### 2.6. Лейаут страницы (Page Layout)
*   **Контейнер (`.wrapper`):** `display: flex; flex-direction: column; gap: 40px;` (или `24px`).
*   **Ограничение ширины:** Контент центрируется с `max-width: $maxContentSize`.
*   **Скроллбар:** Использование миксина скроллбара.

### 2.7. Иконки (Icons)
*   Используются SVG файлы из директории `/public/icons/`.
*   Вставляются через тег `<img>` с настроенной `opacity` (обычно `0.6` или `0.8`).

### 2.8. Мобильная адаптация (Mobile Behavior)
*   Использование миксина `mobileBreakpoint`.
*   Брейкпоинты: `$bpS`, `$bpM`, `$bpL`, `$bpXL`.
*   На мобильных устройствах отступы (`padding`) уменьшаются (например, с `24px` до `16px`), `flex-direction` меняется на `column`, сетки (`grid`) перестраиваются в одну колонку (`1fr`).

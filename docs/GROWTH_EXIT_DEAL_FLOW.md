# INFINITI Growth & Exit Deal Flow

## Founder Journey
Landing Page → Growth & Exit Program → Create Exit Deal Project → Complete Onboarding → Exit Audit → Valuation → Growth Plan → Approve Growth Items → Deal Room → Investor / Buyer Access → Offers → Transaction

## Investor Journey
Invitation → NDA → Deal Room Access → Valuation Access → Questions → Offer → Investment

## Buyer Journey
Invitation → NDA → Deal Room Access → Review → Management Meetings → Due Diligence → LOI → SPA → Acquisition

## Deal Room Structure
01 Company Overview
02 Financials
03 Product Metrics
04 Technology
05 Team
06 Legal
07 Growth Plan
08 Valuation
09 Investor Materials
10 Due Diligence

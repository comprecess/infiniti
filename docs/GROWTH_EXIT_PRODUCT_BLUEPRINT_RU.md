# Growth & Exit Program: Архитектура Продукта (Blueprint)

Данный документ описывает структуру, компоненты и бизнес-логику продукта Growth & Exit Program, базируясь на текущей реализации MVP и бизнес-методологии. Документ служит единым источником истины для понимания того, как продукт работает с точки зрения бизнеса и пользователя.

---

## 1. Суть продукта

**Growth & Exit Program** — это комплексная платформа для подготовки IT-компаний к продаже (M&A) или привлечению инвестиций. Платформа оцифровывает процесс работы M&A-эдвайзера, предоставляя клиенту (Основателю) прозрачную картину текущей стоимости бизнеса и пошаговый план по ее максимизации перед сделкой.

Ключевая ценность продукта заключается в переходе от абстрактного консалтинга к конкретным инициативам (Growth Items), каждая из которых имеет четкую стоимость реализации и прогнозируемое влияние на капитализацию компании.

---

## 2. Ключевые компоненты и шаблоны

Продукт построен на базе модульной архитектуры INFINITI и использует специализированный шаблон проекта.

*   **Шаблон проекта:** `exit_deal`
*   **Модуль Onboarding:** Опросник для сбора первичных метрик (выручка, маржинальность, отток, команда). Данные сохраняются в виде метаданных проекта (`clx_shared_preferences`).
*   **Модуль Valuation (Оценка):** Движок расчета стоимости компании. Позволяет фиксировать базовую метрику (например, ARR или EBITDA) и применять отраслевой мультипликатор.
*   **Модуль Growth Plan (План роста):** Канбан-доска или список инициатив (Growth Items), направленных на устранение рисков или масштабирование бизнеса.
*   **Модуль Deal Room (Комната данных):** Структурированное файловое хранилище (виртуальные папки), необходимое для прохождения процедуры Due Diligence.

---

## 3. Участники и Роли

Система поддерживает сложную ролевую модель, где каждая сторона имеет доступ только к релевантной для нее информации.

1.  **Deal Manager (Внутренний пользователь / M&A Advisor):**
    *   *Роль в системе:* Admin / Resident.
    *   *Права:* Полный доступ к проекту. Проводит оценку, формирует план роста, приглашает внешних участников.
2.  **Founder (Основатель / Владелец бизнеса):**
    *   *Роль в системе:* Client (owner).
    *   *Права:* Полный доступ к клиентскому порталу. Заполняет данные, загружает документы, утверждает и оплачивает инициативы роста.
3.  **Investor (Инвестор):**
    *   *Роль в системе:* Client (investor).
    *   *Права:* Режим "только чтение" для Deal Room. Видит сводную оценку (Summary Valuation) и План роста. Не имеет доступа к процессу онбординга.
4.  **Buyer (Покупатель):**
    *   *Роль в системе:* Client (buyer).
    *   *Права:* Режим "только чтение" для Deal Room. Видит только сводную текущую оценку. План роста и детали онбординга скрыты.

## 4. Клиентский путь (Customer Journey)

Полный цикл работы с клиентом в рамках программы:

1.  **Инициация (Kick-off):** Deal Manager создает проект и отправляет приглашение Основателю.
2.  **Exit Audit (Аудит):** Основатель проходит онбординг, предоставляя базовые метрики.
3.  **Оценка (Valuation):** Deal Manager рассчитывает текущую стоимость бизнеса (Current Value) на основе предоставленных данных.
4.  **Стратегия (Growth Strategy):** Deal Manager формирует список инициатив (Growth Items). Система автоматически рассчитывает потенциальную стоимость (Projected Value) и лучший сценарий (Best Case Value).
5.  **Исполнение (Execution):** Основатель изучает план и одобряет выбранные инициативы. Система автоматически генерирует задачи для команды, коммерческое предложение (Offer) и счет на оплату (Invoice).
6.  **Упаковка (Packaging):** Основатель и команда заполняют Deal Room необходимыми документами (юридическими, финансовыми, техническими).
7.  **Сделка (Deal Making):** Deal Manager приглашает в проект Инвесторов и Покупателей для проведения Due Diligence внутри Deal Room.

---

## 5. Генерируемые документы и артефакты

На данный момент (MVP) система генерирует следующие артефакты:
*   **Коммерческое предложение (Offer / Quote):** Создается автоматически при одобрении инициативы роста.
*   **Счет (Invoice):** Генерируется на основе коммерческого предложения для оплаты услуг.

В будущих фазах планируется автоматическая генерация:
*   *Exit Audit Report (PDF)*
*   *Valuation Report (PDF)*
*   *Investor Memo / Teaser (PDF)*

---

## 6. Связь с биллингом и монетизацией

Уникальность продукта заключается во встроенной монетизации консалтинга. Каждая инициатива в Growth Plan (например, "Прохождение аудита безопасности" или "Найм финансового директора") имеет свою стоимость (`estimated_cost`). 

Когда Основатель нажимает кнопку "Approve", он не просто соглашается с идеей, он **заказывает услугу** у платформы. Интеграция с сервисами `OfferGenerationService` и модулями биллинга (`sys_quotes`, `sys_invoices`) обеспечивает бесшовный переход от консалтинга к транзакции.

## 7. Стратегическая эволюция: INFINITI Network Model

Growth & Exit Program является ядром более широкой стратегической концепции — **INFINITI Network Model** (см. `docs/INFINITI_NETWORK_MODEL.md`).

В рамках этой модели платформа эволюционирует от инструмента M&A-консалтинга к самоусиливающейся экосистеме, где четыре типа участников (Founders, Experts & Advisors, Investors, Buyers) взаимодействуют вокруг единой цели — **увеличения стоимости бизнеса**.

**Текущее состояние:**

> Projects → Talents → CRM → Growth & Exit

**Будущее состояние:**

> Projects → Network → Growth & Exit → Investor Network → Buyer Network → Deal Distribution Engine

**Долгосрочное видение:**

> INFINITI Growth & Exit Operating System

Ключевые принципы Network Model:

1. **Value Creation First** — всё внутри платформы направлено на увеличение стоимости компании.
2. **Experts Before Capital** — эксперты создают рост, капитал лишь ускоряет его.
3. **Self-Reinforcing Network** — каждый успешный проект генерирует новых участников (основателей, советников, инвесторов, покупателей).
4. **Four Layers** — Delivery Layer (исполнение), Growth Layer (стратегический рост), Capital Layer (финансирование), Exit Layer (сделки).

Данная модель не входит в текущий MVP и будет реализовываться поэтапно после завершения валидации Version 1.0.

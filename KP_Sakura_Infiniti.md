## Проект: «Цветение сакуры» — Интернет-магазин японского ресторана

**Исполнитель:** Infiniti Digital  
**Дата:** 26 мая 2026 г.  
**Клиент:** Японский ресторан «Цветение сакуры», Москва

---

## 1. Описание проекта

Полный цикл создания интернет-магазина для японского ресторана с нуля: от генерации визуального контента и разработки уникальной темы до настройки серверной инфраструктуры и наполнения каталога 185 позициями меню.

Сайт представляет собой полнофункциональный интернет-магазин на WordPress + WooCommerce с кастомной темой, адаптивным дизайном, корзиной, оформлением заказа и каталогом блюд с фильтрацией по 17 категориям.

---

## 2. Состав выполненных работ

### 2.1. Серверная инфраструктура

| Работа | Описание |
|--------|----------|
| Аренда и настройка VPS | Выделенный сервер (Ubuntu), установка и конфигурация LAMP-стека |
| Установка WordPress | Развёртывание CMS, настройка безопасности, SSL-подготовка |
| Установка WooCommerce | Настройка плагина интернет-магазина, валюта, доставка, оплата |
| Настройка домена и DNS | Привязка домена, конфигурация DNS-записей |
| Оптимизация сервера | Настройка PHP, MySQL, кеширование, сжатие |

### 2.2. Дизайн и разработка кастомной темы

| Работа | Описание |
|--------|----------|
| Концепция и дизайн | Разработка уникальной визуальной концепции в японском стиле (сакура, тёплые тона, Playfair Display + Nunito) |
| Кастомная тема WordPress | 32 PHP-шаблона, 2400+ строк CSS, кастомный JavaScript |
| Главная страница | Hero-секция, категории, популярные блюда, информация о ресторане, доставка |
| Страница «Меню» (Каталог) | Сетка товаров с фильтрацией по категориям, AJAX-корзина |
| Страница товара | Фото, описание, состав, цена, добавление в корзину, похожие блюда |
| Страница «О нас» | История ресторана, философия, команда |
| Страница «Контакты» | Адрес, телефон, карта, форма обратной связи |
| Корзина и оформление заказа | Полный checkout-процесс WooCommerce |
| Юридические страницы | Политика конфиденциальности, пользовательское соглашение, условия возврата |
| Адаптивная вёрстка | Полная адаптация под мобильные устройства (320px–1920px) |
| Анимации и микро-взаимодействия | Падающие лепестки сакуры, hover-эффекты, плавные переходы |
| Поиск по сайту | Кастомный overlay-поиск по товарам |

### 2.3. Генерация визуального контента (AI)

| Работа | Количество | Описание |
|--------|-----------|----------|
| Фото блюд (AI-генерация) | 185 шт. | Уникальные фотореалистичные изображения каждого блюда меню |
| Обработка и ресайз | 185 × 6 размеров | Автоматическая генерация миниатюр для каталога, карточек, превью |
| Фоновые изображения | 5+ шт. | Hero-баннеры, секции, декоративные элементы |

### 2.4. Наполнение каталога

| Работа | Количество | Описание |
|--------|-----------|----------|
| Создание товаров | 185 позиций | Название, описание, состав, цена, категория, изображение |
| Категории меню | 17 категорий | Роллы, Суши, Сашими, Супы, Горячие блюда, Десерты и др. |
| Настройка атрибутов | — | Вес/порция, состав, аллергены |

### 2.5. Функциональность интернет-магазина

| Работа | Описание |
|--------|----------|
| AJAX-корзина | Добавление товаров без перезагрузки страницы |
| Селектор количества | Кнопки +/− на каждой карточке товара |
| Быстрые ссылки | «Оформить заказ» и «Моя корзина» на каждой карточке |
| Фильтрация по категориям | Навигация по 17 категориям с подсчётом товаров |
| Адаптивная сетка товаров | 4 колонки (десктоп) → 2 колонки (планшет) → 1 колонка (мобильный) |
| Похожие товары | Блок рекомендаций на странице товара |
| Уведомления | Кастомные уведомления о добавлении в корзину |

### 2.6. Техническая поддержка и доработки

| Работа | Описание |
|--------|----------|
| Исправление багов | Многократные итерации исправлений по обратной связи клиента |
| Оптимизация мобильной версии | Тонкая настройка отступов, шрифтов, сеток под мобильные |
| Версионирование | Хранение кода в Git-репозитории (GitHub) |
